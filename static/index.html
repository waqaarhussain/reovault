Recording storage

Oldest completed segments are deleted first. This allowance applies only to ReoVault recordings.

Reducing the allowance can permanently delete older recordings.

Recording controls

Use the dashboard or these commands on your Ubuntu server. The recording choice survives restarts.

recordStart continuous recording
record stopStop recording, keep live view
record statusCheck recording and storage

Your camera connections

Use a separate external RTSP port for each camera. All can point to the same DDNS hostname.

RTSP over TCP is not encrypted. Camera credentials are stored privately on this server and never returned to the browser.
